# 🌤️ Weather App

A sleek and responsive weather forecasting app built with **React**, **Vite**, **Tailwind CSS**, and **Redux Toolkit with RTK Query**.  
It fetches real-time weather data and displays a 7-day forecast with hourly updates.

Hosted on GitHub Pages:

## ✨ Features

- 🔍 Search for any city’s weather
- 📅 7-day weather forecast
- 🕒 Hourly forecast for the current day
- 📸 Dynamic background images based on weather conditions
- ⚛️ Built with modern React (Hooks, Functional Components)
- 💨 Powered by Redux Toolkit + RTK Query
- ⚡ Lightning-fast with Vite
- 🎨 Styled using Tailwind CSS

---

## 📦 Tech Stack

- **React** + **Vite**
- **Tailwind CSS**
- **Redux Toolkit** with **RTK Query**
- **OpenWeatherMap API**
